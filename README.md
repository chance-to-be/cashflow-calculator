# 🏠 부동산 현금흐름 계산기

부동산 매매(매수·매도) 준비를 위한 개인용 현금흐름 시뮬레이터입니다.
**단일 HTML 파일**로 만들어져 있어 인터넷 없이 폰에서 바로 사용할 수 있습니다.

## 폰에서 사용하기

방법 1 — **파일로 저장 (완전 오프라인)**
1. [`index.html`](index.html) 파일을 폰에 다운로드
2. 파일 앱에서 열기 (브라우저로 열림) → 홈 화면에 추가하면 앱처럼 사용 가능

방법 2 — **GitHub Pages 링크**
푸시하면 GitHub Actions가 자동으로 배포합니다 (`.github/workflows/deploy-pages.yml`):

**https://chance-to-be.github.io/cashflow-calculator/**

폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 사용할 수 있습니다.
(무료 플랜에서는 저장소가 public이어야 Pages가 동작합니다)

## 기능

### ① 현금 흐름 (기본 계산)
- 현재 보유 현금 / 매월 반복 유입(지출은 음수로) / 특정 시점 유입·유출 — 항목 자유 추가
- 조회 기간(개월) 설정 → 월별 잔액 **바차트 + 상세 표** (표의 월을 누르면 내역 표시)

### ② 매수 시나리오
- 주택 유형(아파트/빌라) · 전용면적 85㎡ · 세끼고 매수 여부 · 주택 수 · 조정대상지역부터 입력
- **대금 지불 일정**: 날짜|내용|현금|대출 — 예: 28년 6월 선금 2억 / 28년 10월 잔금 1억+대출 5억
  → 잔금 월부터 대출이 실행되어 매월 원리금이 자동으로 빠져나갑니다
- **대출**: 원리금균등 / 원금균등 / 만기일시 + 금리·기간·거치기간
- **취득 부대비용 자동 계산** (각 금액 수정 가능, ↺로 자동값 복원):
  취득세(1~3% 슬라이딩, 중과 8/12%) · 지방교육세 · 농어촌특별세(85㎡ 초과) ·
  중개보수(상한요율) · 국민주택채권 할인비용 · 인지세 · 법무사 보수 · 등기수수료
- ①과 합산한 매수 후 월별 잔액 차트 + 대출 잔액 라인

### ③ 매도 시나리오
- 매도 년월·금액, 실거주 여부(거주 개월), 보증금 승계/반환 선택
- **양도소득세 자동 계산** (세율 전부 수정 가능):
  1세대 1주택 비과세(12억, 조정지역 취득 시 거주 2년 요건) · 단기세율(1년 미만 70%, 1~2년 60%) ·
  기본 누진세율 6~45% · 장기보유특별공제 · 지방소득세 10%
- 중개보수·중도상환수수료(기본 1.2%) 자동 계산
- **실현 수익 요약**: 매도 순수령액, 투입 현금, 이자·원금 누계, 실현 손익과 수익률

### 저장/불러오기
- 입력 시 **자동 저장** (localStorage)
- 시나리오 여러 개를 이름 붙여 저장/불러오기/삭제
- **내보내기/가져오기**: JSON 파일 백업 — 브라우저 데이터가 지워져도 복구 가능

## 개발

- 의존성 0: `index.html` 하나에 전부 (인라인 CSS/JS, 차트는 자체 SVG)
- 계산 로직은 `index.html`의 `CALC_CORE` 블록에 순수 함수로 분리
- 테스트: `node calc.test.mjs` (대출 상환·취득세·중개보수·양도세·통합 타임라인 34개 케이스)
